# 全球进步地图

一颗会自转的 3D 地球，用 5 岁以下儿童死亡率着色；时间可以逐年回放——从 1990 播到 2024，你能看到整颗星球一点点褪去高热色。点进任意国家，会掉进一段滚动叙事：数字一路往下跳，折线一路往上走，最后落到一张 Gapminder 气泡图上。

**零构建、零依赖安装、零网络请求**：双击 `index.html` 即可运行，断网也能完整使用。

视觉：深空底色 `#020617` + 青色强调 `#06B5D4`，数字一律等宽字体加粗；地球海洋半透明（透出背景），经纬线暗青，边缘一圈外发光；陆地用「冷青 → 琥珀 → 红 → 高热」的连续热成像色阶，数值越高越烫。

排版尺度（可用性优先）：

| 层级 | 字号 | 用途 |
|---|---|---|
| 展示级 | 第 1 屏 `5.6em`（≈145px）→ 第 2 屏 `5.6em`（≈90px），整列按 `--stack-fs × --k` 等比缩 | 详情页那个数字 |
| 正文 | 16–17px | 首页说明、详情页尾注 |
| 标题 | 15–19px / 600 | 图表标题、国家名、面板标题 |
| 辅助 | 13–14px | 坐标轴刻度、图例、tooltip、列表数值 |
| 装饰 | 11–12px | 顶部 HUD 条、卡片脚注（纯装饰，不承载信息） |
| HUD 标题 | `clamp(14px, 1.15vw, 17px)` / 0.14em 字距 | 气泡屏左上角那一行 |

次级文字统一用 `#94A3B8`（在 `#020617` 上约 7:1），不再用 `#64748B`。第 2 屏的数字缩放改成**字号过渡**（`transition: font-size`）而不是把整块 `scale(0.46)`。

## 运行

直接双击 `index.html`（`file://` 即可，不需要本地服务器）。

如果想用服务器：
```bash
npx serve .        # 或 python -m http.server 8080
```

## 交互

- **拖动**旋转地球（带惯性），松手后缓慢自转
- **悬停**国家：显示当年数值、较 1990 的变化幅度
- **切换指标**：地球上方一排胶囊（儿童死亡率 / 预期寿命 / 疫苗率 / 电力 / 女性教育），地图着色、图例、榜单、列表、三个 KPI 一起换
- **点击**国家：进入双屏详情页——正中巨大数字 → 滚动后数字缩到左栏、折线滑出 → Gapminder 气泡图。详情页默认继承你在地球上选中的指标
- **时间轴**：播放/暂停（空格键也行），或直接拖到任意年份；播完停在 2024，稍候自动淡出重播
- 顶部三张 KPI 卡（中位数 / 高于高位的国家数 / 低于低位的国家数）随年份与指标实时重算；
  中位数跟指标单位（`8.7 年` / `74.0 岁` / `93.0 %`），两种计数永远写作 `132 个`
- **全球宏观面板**：地球右下角一块毛玻璃 HUD，写死「极度贫困人口比例：1990 年 38% → 2024 年 10%」。
  极度贫困率只有全球口径（国家层面是抽样年，中位 8 个观测点、只有 26 国有 2024 值），
  做不成逐年图层，所以只在宏观面板里讲这一条，不做成地图与详情页
- **开场启动日志**：深空底上逐行打字（含「灵感与数据来源：汉斯·罗斯林《事实》」），点击或任意按键跳过
- **开场直觉测试**：启动日志之后弹《事实》原书 5 道单选题（选项每次打乱，答错会点出对应的思维本能）；右上角 `[ Skip >> ]` 或 Esc 可跳过

### 开场测试怎么重看

- 每个浏览器会话只弹一次（`sessionStorage`）；新开标签页会再弹
- 想强制重看：地址后加 `?test=1`，或在控制台执行 `GPM.calibration.open()`

## 数据

- 指标：**World Bank WDI** `SH.DYN.MORT`（5 岁以下儿童死亡率，每 1000 活产儿）、`SP.DYN.LE00.IN`（出生时预期寿命，岁）；气泡图另用 `NY.GDP.PCAP.PP.CD`（人均 GDP，PPP 国际元）与 `SP.POP.TOTL`（总人口）。
- 国界：**Natural Earth 110m**（经 world-atlas@2），177 个国家多边形，全部能与 WDI 数据对上 ISO2。
- 覆盖：245 个地图区域，其中 196 个有数据；无数据的国家在地球上是中性灰，悬停显示「暂无数据」，不填任何估算值。
- 详情页另有 3 个可按国家拆开的指标（疫苗率、电力可及率、女性平均受教育年限），来自同样的 WDI，见 `data/indicators.js`。
- 重建：`node scripts/build-data.mjs`、`node scripts/build-bubble.mjs`、`node scripts/build-geo.mjs`、`node scripts/build-indicators.mjs`（均需网络，只在开发期运行）；页面本身永远不联网。

### 为什么数据都是 `.js`
`file://` 下 `fetch('data.json')` 会被 CORS 拦掉，这是"离线可跑"最常见的翻车点。`.js` 文件把同一份 JSON 字面量挂到 `window` 全局，内容仍可按 JSON 解析。

### 口径
- 回放区间 **1990 → 2024**；相邻年份线性插值（各国缺测年份连续时平滑过渡，折线图仍按缺测断线）。
- 各国最新可得年份不同（多为 2024），tooltip 和卡片一律显示实际年份，不写"现在"。
- 香港、澳门按 WDI 单独经济体收录，显示为「中国香港特别行政区」「中国澳门特别行政区」；台湾无 WDI 数据，按无数据处理。

## 几个设计决定

| 决定 | 理由 |
|---|---|
| d3.geoOrthographic + Canvas 2D，不用 three.js | 真实的大圆裁剪与地平线；Canvas 每帧重绘 177 个多边形毫无压力，还免掉 WebGL 的拾取复杂度。无需任何纹理图片 |
| 连续色阶而不是 6 档离散色 | 离散分档在年份动画里会"跳色"；连续色阶才能让颜色随时间流动。锚点仍取 `0/5/10/20/40/80/150`，分布观感与原分档一致 |
| 自转很慢（约 86 秒一圈） | 地球是背景，数据才是主角；转太快会抢走注意力。拖动有惯性，停下后恢复慢速自转 |
| 播完停在 2024，淡出后重播 | 回放是"讲故事"的主循环；淡出让重播读作"循环"，而不是时间倒流 |
| 3 个 KPI 随年份重算 | 中位数、高于 50‰ 国家数、低于 10‰ 国家数——三个数字讲清"世界在变好" |
| 滚出视口 / 切后台自动暂停 | 不白烧电；`prefers-reduced-motion` 下不自转、直接停在 2024 |
| 手写 SVG 折线图（详情页） | 需要"缺 1 年就断线"、随容器重算、可展开数据表 |
| 详情页用 `sticky` 双屏舞台 + GSAP Timeline，而不是锁滚动 | 滚动只当触发器（滚一点就播、退回顶部就重置），不参与插值；动画一旦开始就按自己的 2.5 秒走完，滚轮停哪儿都算数。整列只用一个 `transform`，没有逐块定位，所以版式不会散 |
| 左栏是一个 flex 纵列，不是三块绝对定位 | 起点、箭头、终点上下相邻，间距由 flex 流决定；缩放靠一个字号，四块等比跟着变——这是「起点丢失 / 箭头悬空 / 数字错位」的根治办法 |
| 气泡图坐标轴写死量程（GDP 250—200000、寿命 25—88） | 量程固定，气泡才会真的"往右上角挪"；量程跟着数据走的话，看起来就是原地抖动 |
| hash 路由 | `file://` 下 `pushState` 受限，hash 的直链/刷新/后退都安全 |

## 详情页：Sticky 双屏 + GSAP 时间轴

`#/c/XX` 打开后是一个 200vh 的舞台，里面钉住一个 100vh 的视口。没有滚动锁定、没有 scroll-snap，
也没有「滚动进度映射」：进页停在第 1 屏起点，用户一滚就触发**一段固定 2.5 秒的动画**，
在**同一条 GSAP Timeline** 上排成「先变形、后跳动」两个阶段。

| 屏 | 内容 |
|---|---|
| 第 1 屏起点 | 整列居中：`[ 国家 ] — 指标` / `起点 1990 年 · 起点值` / 竖直箭头 / `1990 年 + 起点值`，右侧**没有折线**；顶部一枚透明胶囊显示当前指标，点开可下拉切换；底部一行极小的「向下滚动」 |
| 阶段一 0–0.4s | 只动版式：整列 `translate` 到左侧并等比缩小（`power2.out`），数字一动不动、折线一笔不画；右侧只是把位置腾出来（坐标轴已就位） |
| 阶段二 0.4–2.5s | 版式站定后，数字才开始 1990→2024 跳动，同时折线逐点画出，两者在 2.5 秒一起收住 |
| 第 2 屏终点 | 定格在 `2024 年 · 今天 / 5.7‰`，左栏四块完整、折线在右，画面继续 sticky 固定；再往下滚才滑走进入气泡图 |
| 气泡图 | 紧随舞台之后，进视口才创建 |
| 尾注 | 指标跨度、WDI 指标号、可展开的数据表 |

### 左栏结构：一个 flex 纵列，四块永远同时在

```
.st-stack            display:flex; flex-direction:column; align-items:center
├── .st-head         ① 标题块   [ 国家 ] — 指标                 ← 永远置顶
├── .st-from         ② 起点块   起点 1990 年 53.6 ‰             ← 动画里不隐藏、不删除
├── .st-arrow        ③ 连贯箭头 .st-arrow-line + .st-arrow-tip + .st-arrow-orb
└── .st-now          ④ 动态数字块 年份（今天）+ 巨大数字
```

- **整列只做一次 `transform`**：`p=0` 居中，`p=1` 平移到左侧。起点块和终点块都是这个 flex 流的普通子元素，
  没有 `position:absolute`，所以它们永远共用同一套间距，不可能出现「起点消失、箭头悬空、数字错位」
- **尺寸只认一个字号**：`.st-stack` 上的 `font-size: calc(var(--stack-fs) * --k)`，
  内部四块全部用 `em`。放大/缩小是「整列等比缩」，三块之间的间距比例在任何 `--p` 下都恒定
- 箭头是三个零件拼成**一根**（纯 CSS，没有图片/SVG）：
  - `.st-arrow-line`：`2px` 竖线，`linear-gradient` 从暗青 → 亮青，带外发光；
    高度是 `calc(100% - 9px)`，正好让出底部三角的位置
  - `.st-arrow-tip`：`border` 画的实心向下小三角，尖端就是整根箭头的终点
  - `.st-arrow-orb`：一个 7px 的光点，`@keyframes stOrbDrop` 让它从线的顶端滑到 `top:100%`（正好落在尖端），
    停住 → 涨开 → 消散，循环；`.is-rolling` 期间周期从 2.4s 缩到 0.9s，配合数字跳动做「能量注入」
- 年份标签右侧的「今天」胶囊用绝对定位（`left:100%`），不占位，年份跳动时不会把数字推来推去

### 动效：一条 Timeline，两个阶段

`play()` 用 `gsap.timeline()` 建一条 2.5 秒时间轴，两个 tween **不**同时开始，而是前后接力：

| | 区间 | 缓动 | 写什么 |
|---|---|---|---|
| 阶段一 | 0 → 0.4s | `power2.out` | `--p`：整列 `translate` 位移、等比缩放、折线层透明度与 x 位移、胶囊栏透明度 |
| 阶段二 | 0.4 → 2.5s | `power2.out` | 巨大数字、年份、折线的逐点绘制进度 `chartView.setProgress()` |

- 两个 tween 用 `position` 参数接力：阶段一先把版式摆好，阶段二才动数字——「先变形，后跳动」
- 数字 tween 的起跑时刻 = 版式站定的时刻，所以不会出现「数字跑到一半版式还在飞」
- **滚动完全不参与插值**：滚动只用来判断两件事——滚过舞台 1.5%（几像素）就触发；退回 0.5% 就重置。
  所以滚轮停在哪里、滚得多快，都不影响动画自己播完
- 重置走 380ms 的短补间：数字退回起点、折线清空，画面平滑回到第 1 屏，等下一次触发
  （语义等价 `toggleActions: play none none reset`）
- 终值颜色看指标语义：变好走绿、变差走暗红、方向不明走中性青
- 换指标：第 1 屏切换 = 直接回到新指标的起点（不播、不留在终值，等滚动再播）；已在第 2 屏 = 直接给新指标的定型态
- `≤900` 变成上下两段（整列在上、折线在下），同一套 `--p` 驱动；`prefers-reduced-motion` 下直接落定
- GSAP 3.12.5 内联在 `assets/vendor/gsap.min.js`（和 d3 一样是本地文件），离线可用；
  极端情况下它没加载成功，`timeline()` 会退化成一个 rAF 补间，页面不会卡在第一屏

### 状态：一份指标，两处控件

- 唯一真相是 `GPM.state`（`assets/js/metrics.js`）：初值 = 你在地球页选中的指标，写进 `localStorage`，
  刷新和跨页都不丢，不会重置成儿童死亡率
- 第一屏的下拉胶囊、第二屏的胶囊栏都只做两件事：读 `GPM.state.get()` 上色、写 `GPM.state.set()`
- 换指标：数字与折线淡出（170ms）→ 换数据、重算 Y 轴 → 淡入；两处控件同时高亮，
  连点也不会错乱（`swapToken` 只让最后一次生效）
- 若该国缺当前指标：本页退到第一个有数据的指标，但**不改**全局状态，回到地球仍是原来的选择

### 动效：一条 Timeline，两个 tween

`play()` 用 `gsap.timeline()` 建一条 2.5 秒时间轴，两个 tween 的位置参数都是 `0`：

| | 缓动 | 写什么 |
|---|---|---|
| 动作 A | `power2.out` | 巨大数字、年份、折线的逐点绘制进度 `chartView.setProgress()` |
| 动作 B | `easeGeo` = (`easeOut` + `easeInOut`)/2 | `--p`：整列 `translate` 位移、等比缩放、折线层透明度与 x 位移、胶囊栏透明度 |

- 两个 tween 同时起跑、同一个 duration，所以任何一帧里「版式走了多少」和「数字跳了多少」都是同一时刻的进度，
  不存在「先播完数字再变形」
- 几何单独用 `easeInOut` 会显得「数字先跳完、画面才动」，所以取了与 `easeOut` 的中点——起步跟得上数字，结尾又收得住
- **滚动完全不参与插值**：滚动只用来判断两件事——滚过舞台 1.5%（几像素）就触发；退回 0.5% 就重置。
  所以滚轮停在哪里、滚得多快，都不影响动画自己播完
- 重置走 380ms 的短补间：数字退回起点、折线清空，画面平滑回到第 1 屏，等下一次触发
  （语义等价 `toggleActions: play none none reset`）
- 终值颜色看指标语义：变好走绿、变差走暗红、方向不明走中性青
- 换指标：第 1 屏切换 = 直接回到新指标的起点（不播、不留在终值，等滚动再播）；已在第 2 屏 = 直接给新指标的定型态
- `≤900` 变成上下两段（整列在上、折线在下），同一套 `--p` 驱动；`prefers-reduced-motion` 下直接落定
- GSAP 3.12.5 内联在 `assets/vendor/gsap.min.js`（和 d3 一样是本地文件），离线可用；
  极端情况下它没加载成功，`timeline()` 会退化成一个 rAF 补间，页面不会卡在第一屏

## 已知限制

- 110m 分辨率下，小国（新加坡、香港等）没有独立多边形，地球上点不到——通过**搜索框 + 国家列表**进入（列表项是原生 `<button>`，可键盘操作）。
- 110m 数据在小国与海岸线上有可感知的简化；如需更精细可换 Natural Earth 50m（`build-geo.mjs` 换源即可，体积约 ×4）。
- 1990 年前的历史数据（1960 起）不再展示：地图、趋势图、气泡图统一用 1990—2024 这一段，口径一致。
- 个别国家存在异常尖峰（例如南苏丹 1988 年 780.9‰），这是 WDI 原始数据，未做任何平滑或裁剪，趋势图 y 轴会因此被拉高。
